# Python 콘솔 2048

Python으로 2048 게임의 규칙과 콘솔 화면을 구현한 개인 프로젝트입니다. 게임 진행뿐 아니라 점수 기록과 저장·불러오기 기능을 함께 만들었습니다.

- 기간: 2024.01.08–2024.01.09
- 개발: 권혁원
- 기술: Python, 콘솔 입출력, 텍스트 파일 입출력

## 담당 작업 및 구현

- W/A/S/D 입력에 따른 타일 이동과 같은 숫자의 타일 병합 로직 구현
- 새로운 타일 생성, 점수 누적, 승리·게임 종료 조건 처리
- 게임 시작·진행·종료 및 기록 확인을 위한 콘솔 메뉴 구성
- 상위 점수 기록의 파일 저장 및 조회
- 게임 보드와 점수 등을 저장하고 다시 불러오는 슬롯 기능 구현
- 저장 슬롯의 조회·삭제 처리
